I build autonomous multi-step LLM pipelines — the kind that run unattended and have to be *right*, not just plausible.

The through-line in everything below is one idea: **models make decisions, code enforces them.** An LLM is asked for structured judgement. The rules that must hold every single time are checked deterministically, in code, where nothing can talk its way around them.

## 02 — How these are built

| | |
|---|---|
| **Ingest** | Transcripts, documents, leads and accounts normalised into one shape |
| **Retrieve** | Embeddings and semantic search pull the evidence the model is allowed to use |
| **Generate** | Multi-model routing with structured outputs, so the result is machine-checkable |
| **Validate** | Deterministic gates — schema, rules, duplicates, brand constraints |
| **Critique** | A separate model grades the output against the evidence; the maker never grades its own work |
| **Ship** | Containerised behind Traefik, managed by PM2, deployed through CI/CD with rollback |
